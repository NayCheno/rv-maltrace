\section*{Ethics Considerations}

This paper uses only controlled synthetic and malware-like workloads; no uncontrolled malware execution is performed. Any future real-malware experiments must define containment, sample lineage, release policy, and artifact-sanitization procedures before they are cited as paper evidence. The artifact package separates public summaries from raw board and host logs, so that reproducibility is supported without unrestricted publication of every raw trace.
