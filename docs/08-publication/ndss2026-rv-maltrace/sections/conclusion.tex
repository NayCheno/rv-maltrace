\section{Conclusion}

\rvmt demonstrates a path from RISC-V hardware trace records to controlled
Linux behavior summaries. The current CVA6/Genesys2 implementation supports
trace correctness tests, source-labeled reconstruction, local code-attribution
tests, and reproducible artifact checks under the current evidence directory. Real
malware validation, production transport, JTAG RAM boot, SD-card-free kernel
update, and cycle-overhead are outside the evaluated scope.

The next step for a submission-ready paper is to replace remaining prose-level
summaries with final figures, quantitative tables, and related-work positioning
while keeping the same scope.
