\section{Conclusion}
\label{sec:conclusion}

We presented \rvmt, a hardware-assisted behavior tracing system for RISC-V Linux that connects CVA6 hardware trace events to source-labeled behavior reconstruction. Our key insight is that labeling each reconstructed field with its provenance source enables auditable behavior analysis without overstating what the hardware alone recovered. By keeping hardware trace fields separate from ELF metadata, runtime process maps, and reference logs, \rvmt produces behavior summaries whose evidence is explicit and verifiable.

Our evaluation demonstrates correct trace capture: all [N] directed tests pass, confirming correct event ordering, syscall pairing, and privilege transitions. RV-MalTrace achieves [X\%] source-label coverage, ensuring that every reconstructed field carries a correct provenance label. It achieves [Y\%] code-attribution accuracy across [N] test cases covering PIE/ASLR, dynamic loading, fork/exec, and stripped binaries. All reported results are backed by a fully reproducible artifact package with SHA-256 verified manifests.

Future work includes production trace streaming, cycle-level overhead measurement, and real malware validation on the RISC-V platform. We release \rvmt and its artifact package at [URL].
