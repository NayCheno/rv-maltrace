\section{Related Work}

\textbf{Software tracing and reference runs.} Tools such as strace observe
syscall behavior from within the software environment, while QEMU can provide
emulation-based execution logs \cite{strace,bellard-qemu}. \rvmt uses such
sources only as references. Its contribution is the separation between
reference-derived fields and hardware trace evidence.

\textbf{Kernel instrumentation.} eBPF-based tracing provides powerful kernel
observability and is widely used for production diagnostics and security
monitoring \cite{ebpf}. It remains software-visible and kernel-mediated. \rvmt is
complementary: it studies the evidence boundary of a hardware-assisted RISC-V
trace path rather than replacing kernel instrumentation.

\textbf{RISC-V hardware trace.} RISC-V systems and open-source cores such as
CVA6 make it practical to prototype trace logic at the architectural boundary.
The challenge addressed here is not only trace capture, but behavior
reconstruction with explicit evidence sources for security workloads.
