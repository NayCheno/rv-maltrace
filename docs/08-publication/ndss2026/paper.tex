\begin{abstract}
This skeleton is a host-side LaTeX build artifact for the RV-MalTrace
Genesys2/CVA6 evidence package. It is intentionally not a complete anonymous
submission and is used only to validate that the local publication build path
is available.
\end{abstract}

\section{Scope}
The current package covers controlled Genesys2/CVA6 BRAM marker-window evidence,
local semantic reconstruction artifacts, and reproducibility manifests. It does
not claim real-malware validation, malware detection accuracy, production
streaming/DMA throughput, or accepted full hardware-derived pointer strings.

\section{Artifact Boundary}
The canonical current evidence selector is
\texttt{results/evaluation/genesys2-cva6/current/latest\_manifest.json}.
External closure summaries remain open until accepted by their artifact-backed
intake gates.
