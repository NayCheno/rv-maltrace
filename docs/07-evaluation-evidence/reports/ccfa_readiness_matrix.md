- One P0 failed attempt is retained: `results/board/genesys2_trace_validation/20260612-p0-bram-repetitions/fork_exec/rep_03/` has BRAM dropped count 3612 and wrap count 4.
- Current accepted trace evidence is marker-window BRAM evidence, not a production streaming/DMA sink throughput claim.
